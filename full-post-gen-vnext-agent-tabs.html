Full Post Gen vNext — Insight-to-Post Agent Architecture

整理 Full Post Gen 的六个用户场景、前端入口、insight 默认规则，以及推荐的新 agent 架构：Content Insights 与 PostStrategyBrief 放在同一路径下，但业务上仍是“分析 → brief 输出”两层；Full Post Gen 负责生成可发布草稿。

User Case Summary

面向市场人员的六个入口总览。

ID User Case 用户想要什么 主要产出 Insight step Status
UC1 Create an editorial post 把 topic 或 idea 转成 organic social post。 Post Draft No 已实现

UC5 Analyze a competitor folder 查找过去 7 天表现最好的 competitor posts。 Insights + strategy + Post Draft Yes 规划中
UC6 Find industry winners 发现我所在 category 的 winning posts，并推荐 content angles。 Topic options + optional Post Draft Yes 规划中

Competitor Folder and Category Rules

UC5 和 UC6 在分析前需要一个 soft setup step。

UC5 — Competitor Folder

如果只有一个 folder 或存在 current UI folder，则使用它并说明假设；如果存在多个 folders 且没有 current context，则让用户选择。

I found multiple competitor folders. I can use "Beauty Competitors" and the past 7 days by default. If you want another folder or time range, tell me; otherwise I will continue with that.

UC6 — My Page Category

如果有 selected 或 connected My Page category，则优先使用；如果连接了多个 pages，则询问或软确认 current page。

I can use BusinessFocus as the page context and "business & tech news" as the category. Unless you want another page or category, I will analyze the past 7 days.

Recommended Agent Framework

将 insight discovery 与 post generation 拆开。

高层架构

Root / Auto Router → Content Insights Agent
same insights path → PostStrategyBrief
same insights path → Full Post Gen Agent → Image Gen Queue → Post Draft

说明：Content Insights Agent 与 PostStrategyBrief 在工程上放在同一个 insights skill/path 下；业务表达上仍然是“分析 → brief 输出”两层。

层级 负责内容 不负责内容
Content Insights Agent Buzz analysis、folder/category resolution、过去 7 天默认规则、top post commonality、topic options。与 PostStrategyBrief 同属一个 insights path。 Caption finalization、image generation、draft assembly。
PostStrategyBrief Content Insights path 下的第二层业务输出，将 insight conclusion 整理成 Full Post Gen 可消费的 strategy brief。 查询 Buzz 数据、生成图片、落 draft。
Full Post Gen Agent Editorial/ad generation、Buzz single-post remix、caption、overlay、image prompt、draft assembly。 Ranking competitor folders、category-level Buzz discovery、insight brief generation。
Publish Flow Account validation、publish confirmation、Meta execution、scheduling。 Creative strategy 与 insight analysis。

Decision Log

本次讨论形成的关键产品决策。

Decision 建议
Insight references location 使用单独的 Content Insights skill/path；其中 insight analysis 与 PostStrategyBrief 是两个业务层、两个 md 文档，再 hand off 给 Full Post Gen。
Editorial 与 ad references 使用独立的 editorial.md 与 ad.md runtime references。
UC5 folder confirmation 当 folder ambiguous 时需要确认；有 current UI folder 或唯一 folder 时可作为 soft default。
Insight period 默认使用过去 7 天，并在回复中说明。
Frontend options Auto mode 展示全部六个；Full Post Gen mode 展示三个直接生成 options。
