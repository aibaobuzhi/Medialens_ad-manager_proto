Get started

Connect your AI assistant

MediaLens runs a remote MCP server over HTTP. You sign in with your MediaLens account, and every tool works inside the workspace you choose.

  1. Add the server. In your assistant’s connector or MCP settings, add a custom server with your MediaLens MCP URL.
  2. Sign in. A MediaLens login window opens. Sign in and pick the workspace to connect.
  3. Check your access. Ask: “What can I access in MediaLens?” The assistant calls ml_account_get_my_access and lists your plan, modules and data window.
  4. Ask a question. For example: “Which beauty advertisers ran the most Instagram Story ads last week?”

Your MCP URL is shown in MediaLens under workspace settings. Every tool reads data only, except two Social Pulse tools that create or update monitoring tasks; your assistant asks you to confirm before they run.

# Add MediaLens as a remote MCP server
claude mcp add --transport http medialens <YOUR_MEDIALENS_MCP_URL>

# Then run /mcp in Claude Code and choose
# Authenticate to sign in with MediaLens.
{
  "mcpServers": {
    "medialens": {
      "type": "http",
      "url": "<YOUR_MEDIALENS_MCP_URL>"
    }
  }
}

Plans & access

Tools follow the same rules as the MediaLens web app. What a connection can use depends on your organization’s plan, add-ons and your role.

What decides itEffect on tools
Modules in your planTools of a module you don’t have return a permission error.
Data historyDate ranges are capped by your plan’s history; longer ranges are shortened automatically.
Countries and platformsResults cover the markets and Social Listening platforms in your plan.
Add-onsSome tools need an add-on, for example Echomaker for private profile insights.
Your roleAd Manager and My Page only show accounts and pages you can view in MediaLens.

Not sure what is available? Call ml_account_get_my_access first.

// Example prompts
"What can I access in MediaLens?"

"Show the top 10 viral Facebook posts in Hong Kong this week."

"Compare the Instagram performance of these three competitor accounts last month."

Conventions

Tool naming

Every tool name follows one pattern, so you can tell what it does from the name.

ml_{module}_[ai_]{verb}_{object}[_by_{condition}]

VerbMeaningExample
getOne object by its id, or one report about a subject.ml_page_get_fb_page
listA list of objects in a scope, with optional filters and sorting.ml_post_list_fb_posts_by_page
searchObjects that match a text, name or keyword query.ml_post_search_fb_posts_by_text
generateA plan or recommendation produced by MediaLens AI.ml_influencer_ai_generate_campaign_plan
create updateWrites data. Your assistant asks you to confirm first.ml_social_pulse_create_task

ai_ in a name means the main result comes from MediaLens AI. Platforms are written as fb, ig, threads, lihkg, xhs and bk.

Conventions

Limits & pagination

Every tool that returns a list takes a limit. If you don’t say how many you want, the tool returns its default; if you do, it returns that many, up to its maximum. Each tool page shows its rule under Output data limit.

Limit ruleWhat you get
default 20, max 10020 results unless you ask for more; up to 100.
default all, max 100Everything that matches, up to 100, unless you ask for fewer.
… per page; pagination: page + has_moreResults come in pages. Use page for the next page; has_more tells you whether more results exist.
… ; totalThe response also includes the total number of matching results.
top 20, fixed 6, max 6A fixed part of a report, such as the top 20 ads. Not adjustable.
per keyword, per platformThe limit applies to each keyword or platform separately.

Asking for more than the maximum is not an error: the tool returns the maximum. For paginated tools your assistant fetches the next pages; for the others it tells you the cap.

{
  "name": "ml_post_list_fb_posts_by_page",
  "arguments": {
    "page_id": "<page_id>",
    "limit": 100,
    "page": 2
  }
}
{
  "posts": [ /* 100 posts */ ],
  "page": 2,
  "limit": 100,
  "has_more": true,
  "total": 230
}

Conventions

Quota

A tool uses quota only when the same search in the MediaLens web app would. Each call uses 1 from the quota below; every other tool is free to call.

QuotaPer callTools

When the quota runs out, the tool returns an error saying which quota is used up. Large responses don’t use more quota, but they do use more of your AI assistant’s tokens.

Conventions

Errors

Errors come back as a code and a message your assistant can act on.

CodeMeaningWhat to do
NOT_FOUNDNothing matches, or the id doesn’t exist in your workspace.Check the name or id; look it up with a search tool first.
AD_NOT_FOUNDAn ad id isn’t in this ad account.Get ad ids from Ad Manager list tools.
UPSTREAM_ERRORA data source didn’t respond in time.Narrow the date range or add countries, then retry.
SERVICE_UNAVAILABLEThe service is temporarily unavailable.Retry later. For write tools, check whether the task was already created first.
 
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Unknown product category. Call ml_ad_intelligence_list_product_categories for exact names."
  }
}
