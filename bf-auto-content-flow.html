三段流程

每天 10:00 HKT 自动触发一次。
Stage 1选题
  • HK / CN / Global 三层来源并行扫描
  • 输出 20 条：标题 + brief + 该题全部来源
  • 剔除规则 → 100 分评分 → 取前 N
  • 编辑勾选确认后才进生成
  • 选中的再做深：≥3 独立来源 + 原始资料
Stage 2生成初版交付
  • 先文章，后图片，顺序不可改
  • 01_文章全文.md（8 区段锚点）
  • 02 直版封面 4:5
  • 03–06 四张资讯图 4:5
  • 07 横版封面 1000×525
  • 写入 MediaLens（取代 Drive / Notion）
Stage 3组装 post
  • engineering，不用 AI：可重现、零幻觉
  • FB image：caption s1..s7 + 图 02
  • IG carousel：caption s1..s8 + 图 02→06
  • 缺区段 / 图不齐 / 超字数 → 不建立 post
隔离怎么成立：bf_agent 是自己的 root agent，不挂进 medialens_agent.sub_agents。 ADK 的 peer transfer 一律经 parent 转发 —— 没有共同 parent，就没有转进来的路径。 另外 agent 本身也设了 disallow_transfer_to_parent / to_peers = True，把转出方向也关掉。
